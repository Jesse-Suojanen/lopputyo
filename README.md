# lopputyo

Projekti sisältää Gitin jatkotoimintojen harjoitukset.



äytetyt komennot



git clone – repositorion kloonaaminen.



git add – muutosten lisääminen seuraavaan commitiin.



git commit – muutosten tallentaminen versiohistoriaan.



git push ja git pull – muutosten lähettäminen ja hakeminen GitHubista.



git branch ja git switch – haarojen hallinta.



git merge – haarojen yhdistäminen.



git stash ja git stash pop – keskeneräisten muutosten väliaikainen tallentaminen ja palauttaminen.



git revert – aiemman commitin muutosten kumoaminen.



git cherry-pick – yksittäisen commitin poimiminen toisesta haarasta.



git rebase – haaran historian päivittäminen uuden lähtöpisteen päälle.



git tag – version merkitseminen.



git status, git log ja git diff – tilanteen, historian ja muutosten tarkastelu.



git check-ignore – .gitignore-säännön testaaminen.



\## Mitä opin?

Opin luomaan haaroja, yhdistämään muutoksia ja

ratkaisemaan merge-konflikteja.
